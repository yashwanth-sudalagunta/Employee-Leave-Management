# Usability test plan

## Objective

Check whether users can submit and track leave requests and whether managers can process approvals without confusion.

## Participants

Use 5–8 volunteer testers or simulated role-based walkthroughs. Do not use real employee data.

## Tasks

1. Find the available leave balance.
2. Submit a three-day annual leave request.
3. Find the submitted request and confirm its status.
4. As a manager, find the pending request.
5. Reject a request and provide a comment.
6. Find a previously approved request.

## Measures

- Task completion rate
- Time on task
- Number of user errors
- Number of requests submitted with invalid dates
- System/API response time
- Participant feedback and severity of usability issues
